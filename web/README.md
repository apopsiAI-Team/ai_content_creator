# Δημιουργός Εκπαιδευτικού Υλικού

Web εφαρμογή για παραγωγή εκπαιδευτικού υλικού με βιβλιογραφία από σχέδιο διδασκαλίας.

## Χαρακτηριστικά

- **Upload** εκπαιδευτικού σχεδιασμού (docx)
- **Εμφάνιση ενοτήτων** από το έγγραφο
- **Παραγωγή υλικού** ανά 20 σελίδες με έγκριση
- **Λειτουργία οδηγιών**: Αυτόνομη ή Καθοδηγούμενη
- **Εξαγωγή σε Word** με βιβλιογραφία APA
- **Claude Opus 4.5** για παραγωγή περιεχομένου

## Εγκατάσταση

```bash
cd web
npm install
```

## Εκτέλεση

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

## Χρήση

1. Ανέβασε το αρχείο εκπαιδευτικού σχεδιασμού (.docx)
2. Επίλεξε ενότητα
3. Εισάγαγε το Anthropic API key
4. Επίλεξε λειτουργία (Αυτόνομη ή Καθοδηγούμενη)
5. Πάτα "Έναρξη Δημιουργίας"
6. Έγκρινε ή απόρριψε κάθε τμήμα 20 σελίδων
7. Εξαγωγή σε Word όταν είσαι ικανοποιημένος

## Τεχνολογίες

- React + TypeScript
- Vite
- Zustand (state management)
- Framer Motion (animations)
- Anthropic Claude API (Opus 4.5)
- mammoth (DOCX parsing)
- docx (Word export)
